About

METO Bulk Video Downloader runs on your machine: queue links, download with open-source tooling, and browse everything in the library.

Open source

This app bundles and orchestrates trusted open-source utilities—see the project README for details (for example yt-dlp, Flask, and Python).

Features & Architecture

Cloud Ready

Fully compatible with Docker and Dokploy. Configure everything seamlessly via .env variables.

Flexible Database

Runs on a zero-config SQLite file by default, but natively supports MySQL and PostgreSQL for production environments.

Secure Access

Includes an optional, cookie-based authentication system. Set a username and password to lock down the UI for public servers.

Library Management

Organize massive collections with grid/list views, metadata tagging, favoriting, and multi-select bulk operations.
